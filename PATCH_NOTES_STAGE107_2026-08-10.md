# Nexus Panel 1.0.3 — исправление 502 при удалении с узла

Дата: 2026-08-10

## Симптом

При выборе большого количества клиентов и действии «Удалить выбранных клиентов из узла» браузер открывал страницу:

```text
HTTP ERROR 502
```

## Причина

Для каждого клиента агрегатор загружал и просматривал весь глобальный список 3x-ui перед удалением, а затем повторял ту же проверку после удаления. Массовая операция получала квадратичную нагрузку по сети, памяти и JSON. При большой панели процесс Node мог быть остановлен или перезапущен, после чего Nginx возвращал 502.

## Исправление

- Для актуального 3x-ui используется штатный `POST /panel/api/clients/bulkDetach`.
- Email отправляются пакетами не более 200 записей.
- `detached`, `skipped` и уже отсутствующие клиенты корректно удаляют только связь с выбранным узлом.
- Сами клиенты агрегатора и их связи с другими узлами сохраняются.
- Старые версии 3x-ui используют поштучный fallback без загрузки полного списка клиентов.
- Для страницы длительной операции установлено `X-Accel-Buffering: no`, заголовки отправляются сразу, heartbeat не задерживается в Nginx.

## Проверка

```bash
npm run check
npm test
```

Интеграционный тест удаляет с узла 225 клиентов, проверяет два пакетных запроса (200 + 25), отсутствие обращений к `/clients/list`, удаление локальных связей, сохранение клиентов агрегатора и работающий процесс Node.
