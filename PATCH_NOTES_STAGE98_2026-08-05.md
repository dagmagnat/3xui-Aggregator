# Stage 98 — онлайн-клиенты и SUB/JSON QR

Дата: 2026-08-05

## Исправлено

- Статус «В сети» на странице клиентов обновляется автоматически каждые 8 секунд.
- Клиент, появившийся онлайн, сразу получает зелёный статус; строка кратко подсвечивается.
- Верхняя карточка «В сети» показывает текущее количество и загорается зелёным, когда есть подключённые клиенты.
- Проверка онлайн защищена от зависания: запрос прерывается через 12 секунд, предыдущие корректные статусы не сбрасываются.
- Фильтр «В сети» повторно применяется после каждого обновления статусов.

## SUB и QR

- SUB-ссылка и SUB QR теперь доступны для обычных Xray/Reality-клиентов, а не только для клиентов H1Cloud.
- В новом списке клиентов кнопка QR открывает сразу два варианта: SUB и JSON.
- QR-коды SUB и JSON имеют одинаковые квадратные размеры и показываются рядом.
- Для обоих форматов добавлены отдельные кнопки копирования.
- Одиночные QR-коды, включая VPN-конфигурации, также выводятся без растягивания.

## Установка поверх работающей панели

Скопируйте изменённые файлы с сохранением каталогов, затем пересоберите контейнер:

```bash
docker compose up -d --build
docker logs --tail=200 3xui-aggregator
```

После обновления выполните жёсткое обновление страницы браузера: `Ctrl+F5`.
