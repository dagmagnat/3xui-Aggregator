# Точечное управление клиентами по узлам — stage94

## Добавление только отсутствующих клиентов

На странице **Узлы** у каждого сервера появилась кнопка `Добавить клиентов`.
Она:

1. проверяет только выбранный узел;
2. один раз читает его текущий список клиентов;
3. сравнивает клиентов по UUID, email и subId;
4. создаёт только отсутствующих;
5. существующих не обновляет;
6. восстанавливает локальную связь `client_nodes`, если клиент уже есть на сервере, но связь отсутствует в агрегаторе;
7. не перезаписывает совпадение email/subId с другим UUID — такое совпадение отмечается как конфликт.

Та же операция доступна в окне **Клиенты → Импорт и синхронизация → Добавить отсутствующих клиентов на один узел**.

Операция поддерживает прогресс и кнопку **Безопасная отмена**. Уже созданные клиенты остаются, новые после точки отмены не запускаются.

## Удаление выбранных клиентов из конкретного узла

При фильтре клиентов по узлу массовое действие автоматически выбирает тот же узел.
Можно:

1. отфильтровать клиентов по узлу;
2. выбрать всех показанных;
3. снять отметки с клиентов, которых нужно оставить;
4. нажать `Удалить из текущего узла`.

Удаление выполняется сначала в 3x-ui, и только после успешного ответа удаляется связь из агрегатора. Сам клиент и связи с остальными узлами остаются.

Если узел недоступен, локальная связь не удаляется. Это предотвращает расхождение между агрегатором и фактическим состоянием 3x-ui.

Массовое удаление также поддерживает безопасную отмену и останавливается после двух последовательных сетевых ошибок.
