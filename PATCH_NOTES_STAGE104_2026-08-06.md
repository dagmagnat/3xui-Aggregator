# Stage 104 — восстановление информации клиента в Happ

Дата: 2026-08-06

## Причина исчезновения блока

В Stage 103 на странице настроек были две отдельные формы:

- «Happ Control App»;
- «Общие настройки».

Форма «Общие настройки» не отправляла поля Happ, но её обработчик всё равно
записывал отсутствующие значения как `0` и пустые строки. После обычного
сохранения общих настроек отключались:

- информационный блок Happ;
- шаблон с логином и количеством устройств;
- дублирование через `announce`;
- описание серверов;
- `subscription-userinfo` и автообновление.

Также очищался текст помощи. Поэтому Happ продолжал показывать узлы, но блок
под названием подписки пропадал.

## Что исправлено

- Общая форма больше не изменяет настройки Happ, которых в ней нет.
- Настройки Happ изменяются только через форму «Happ Control App».
- При первом запуске Stage 104 автоматически распознаётся характерный сброс
  Stage 103 и восстанавливаются:
  - `👤Логин: {login}`;
  - `📱Количество устройств: {ip_usage}`;
  - предупреждение об обновлении подписки;
  - `announce`, `subscription-userinfo` и автообновление;
  - подпись типа сервера.
- После автоматического восстановления ревизия подписки повышается, чтобы Happ
  не оставил старый ответ в кэше.
- Клиентская информация дополнительно помещается в тело JSON-подписки. Это
  резервный вариант для версий Happ, которые иногда не используют HTTP-заголовок
  `announce` при импорте массива JSON-конфигураций.

Восстанавливаемый текст:

```text
👤Логин: {login}
📱Количество устройств: {ip_usage}
⚠️ Если VPN не работает — отключите его, обновите подписку 🔄 и подключитесь заново ✅
```

## Установка поверх Stage 103

Сделайте резервную копию базы:

```bash
cd /opt/3xui-aggregator
cp data/app.db data/app.db.backup-stage104-$(date +%F-%H%M%S)
```

Замените файлы из архива Stage 104 и перезапустите контейнер:

```bash
cd /opt/3xui-aggregator
docker compose up -d --build
docker logs --tail=200 3xui-aggregator
```

В журнале при восстановлении повреждённых настроек появится строка:

```text
Stage104: restored Happ client info that was cleared by the Stage103 general settings form.
```

После запуска в Happ:

1. отключите VPN;
2. нажмите обновление подписки;
3. снова подключитесь.

Удалять подписку и добавлять её заново обычно не требуется.
