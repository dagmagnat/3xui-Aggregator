# Stage 103 — горизонтальные QR и тихое копирование

## Что изменено

- Окно SUB/JSON перестроено в горизонтальный макет: два одинаковых QR-кода стоят рядом.
- На узких экранах карточки остаются рядом и уменьшаются; вертикальный режим включается только на совсем узких экранах.
- Надпись «Скопировано» больше не заменяет иконку или текст кнопки. Успешное копирование показывается короткой зелёной подсветкой.
- В окне быстрой информации клиента появились отдельные кнопки «Копировать SUB» и «Копировать JSON».
- Кнопка «Все ссылки и QR-коды» сохраняет доступ к SUB, JSON и HAPP.

## Установка

Распакуйте архив изменённых файлов поверх каталога проекта и пересоберите контейнер:

```bash
cd /opt/3xui-aggregator
docker compose up -d --build
docker logs --tail=200 3xui-aggregator
```

После обновления выполните в браузере `Ctrl+F5`.
