# Stage 97 hotfix — 2026-08-04

## Что исправлено

1. Страница `/settings` больше не падает из-за отсутствующей переменной `showJsonLinks`.
2. Настройка «Показывать JSON-подписку клиентам» теперь создаётся в БД и сохраняется без удаления настройки HAPP.
3. В современной таблице клиентов колонка «Привязанные узлы» заменена на приоритетную колонку «Комментарий».
4. Колонка «Скорость» получает свежие данные с узлов, показывает «Нет трафика» при нулевой активности и подсвечивается при реальном трафике.
5. Карточки сводки «Клиенты», «В сети», «Срок истёк», «Скоро закончатся», «Отключено» и «Активны» работают как фильтры.
6. Добавлены варианты фильтра «Активные» и «Сейчас в сети» в выпадающий список.

## Почему появилась ошибка настроек

Шаблон `views/settings.ejs` уже обращался к `showJsonLinks`, но маршрут `/settings` в `app.js` эту переменную не передавал. EJS выбрасывал `ReferenceError`, а production-режим показывал только код ошибки.

Архив `3xui-Aggregator-fix-online-settings-2026-08-03.zip` нельзя накатывать целиком поверх текущего проекта: его `app.js` одновременно удаляет крупные блоки сохранения настроек подписки и маршрутизации. В этом hotfix взяты только безопасные и необходимые изменения.

## Установка поверх работающего проекта

Сначала сделайте резервную копию каталога проекта и базы `data/aggregator.db`.

Распакуйте архив changed-files в корень проекта с заменой файлов, затем выполните:

```bash
docker compose up -d --build
docker logs --tail=200 3xui-aggregator
```

Каталог `data` заменять не нужно.
